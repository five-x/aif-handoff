## Trusted-State Rule

Trusted audit state is not allowed to come from raw report prose alone.

- Ledger evidence may influence trusted state only through manifest-bound `auditEvidenceUnits` with ledger requirements enabled in `evaluateTaskCompletionEvidence()` and `validateAuditReportArtifact()`.
- Committed blob validation may influence trusted state only through `verifyAuditArtifactLifecycle()` and persisted lifecycle-valid `validationDetails`.
- Raw report text may influence diagnostics, repair guidance, review comments, and operator display, but it cannot satisfy trusted completion or trusted synthesis without ledger evidence and committed blob/lifecycle proof.

Concrete trust proof is centralized in [packages/shared/src/taskCompletionEvidence.ts:1321](../../packages/shared/src/taskCompletionEvidence.ts): `hasTrustedAuditArtifactProof()` requires validator `ok`, valid manifest, trusted source classification, `requireAuditLedgerEvidence === true`, lifecycle `ok`, `artifact_state_valid`, and committed validation `ok`.

## State Influence Matrix

| Input                          | Trusted production state                                                                                                                | Diagnostic/operator state                                                                                                                          |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ledger evidence                | Allowed only when passed as `auditEvidenceUnits` and `requireAuditLedgerEvidence` is true. Required by trusted completion.              | Allowed for diagnostics and repair guidance; absence can produce actionable issue codes.                                                           |
| Committed blob validation      | Required through `verifyAuditArtifactLifecycle()` for trusted completion, trusted roadmap validity, and trusted synthesis input.        | Missing or mismatched committed blobs produce diagnostic/blocking reason codes such as `audit_artifact_uncommitted` and `committed_blob_mismatch`. |
| Raw report text                | Allowed as the text under validation, but not enough to become trusted without manifest, ledger, lifecycle, and committed revalidation. | Allowed for validator diagnostics, review feedback, runtime tool output, and UI display.                                                           |
| Legacy raw synthesis `reports` | Not allowed to produce trusted synthesis. They become blocking untrusted source artifacts.                                              | Allowed only to explain weak/untrusted synthesis inputs.                                                                                           |
